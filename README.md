
# TASK-1 --> 🗳️ Blockchain-Based Voting Management System

A simple, secure, and transparent console-based Voting Management System implemented in **Python** using core Blockchain concepts. This project demonstrates how decentralized ledger technology can eliminate single points of failure, ensure data integrity, and prevent unauthorized tampering in voting processes.

---

## 📌 Features

* **Custom Block & Chain Structure:** Each block securely stores vote details, a timestamp, a unique nonce, and the SHA-256 hash of the previous block.
* **Proof-of-Work (PoW):** Features a mining algorithm to ensure computational validity before adding blocks to the chain.
* **Cryptographic Anonymity:** Uses `SHA-256` hashing to anonymize voter identities while maintaining verifiable records.
* **Double-Voting Prevention:** Tracks voter state to ensure each registered voter can cast only one valid vote.
* **Chain Integrity Verification:** Includes an automated validation module that recalculates hashes across the ledger to instantly detect data tampering.

---

## 🛠️ Tech Stack & Requirements

* **Language:** Python 3.x
* **Standard Libraries Used:** 
  * `hashlib` (For SHA-256 cryptographic hashing)
  * `time` (For generating block timestamps)

---

## 🚀 Getting Started

### 1. Prerequisites
Ensure you have Python 3 installed on your machine. You can check your version by running:
```bash
python --version
```
